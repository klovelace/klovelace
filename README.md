## How I approach problems

1. **Frame the decision.** Identify what a stakeholder needs to decide, the alternatives, and the evidence that would change the choice.
2. **Select credible methods.** Use experiments, quasi-experimental designs, measurement frameworks, or predictive methods based on the identification problem and available data.
3. **Make evidence inspectable.** Document assumptions, provenance, uncertainty, quality checks, and failure modes.
4. **Build for use.** Translate the method into a product, operating workflow, or feedback process that supports iteration and adoption.
